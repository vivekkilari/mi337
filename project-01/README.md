## What?

This is a tool to make aqueduct-like representations on flat planes. By specifying a spline input in Blender, a series of pillars along with an aqueduct path above.



\## How-To

Create a Bezier spline in Blender. Add the Aqueduct Geometry Nodes system to the spline. Now adjust the ends of the spline along the XY plane to generate an Aqueduct!



To make iteration easy, you can disable the rocky topology by setting "Rockify Active" off in the modifier options. Additionally, if you want to see the rockiness, you can turn it on and control subdivision level separately through the "Subdivide" option and "Rock Detail".



By adjusting the "Pillar Gap", you can control how far apart consecutive pillars are. Additionally, "Min Arch Height", "Max Arch Height", and "Arch Top Offset" help control the size of the upper water path and supporting arches.
